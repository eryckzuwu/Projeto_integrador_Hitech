# Projeto_integrador_Hitech
projeto de banco de dados de uma empresa ficticia, a empresa opera criando sistemas de computadores feitos por pedidos dos clientes. Ela separa seus pedidos por nível de habilidade, e posição profissional dentro da empresa.
foram utilizados triggers para definir no código sql o as necessidades da regra da própria empresa, resolvemos as dores do projeto, e o código executa comandos simples, como SELECT, DELETE, e também algum indicadores como o WHERE. o sistema foi dividido em 7 tabelas principais, isso serve para organização e para o código funcionar bem. utilizamos PRIMARY KEYS e chaves estrangeiras para conectar as tabelas entre si. as triggers também precisavam das chaves estrangeiras para funcionar, como por exemplo: para verificar se um funcionário tem o cargo necessário para realizar uma tarefa de um projeto, ele deve acessar "TABELA_FUNCIONÁRIO", e "TABELA_TAREFAS", então para a trigger acessar estas duas foi necessário a adição de uma chave estrangeira. além de outras funções que necessitavam.
